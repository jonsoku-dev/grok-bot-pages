Money Forward Claude 100-tool routing cost study — moneyforward-claude-100-tools-routing​

Money Forward가 Claude(Sonnet 5)에 테마파크 운영 API 도구 100개를 두고 전량 투입(캐시 유/무), Tool Search, 카테고리 지연 로딩 4방식을 10쿼리로 실측했다. 전량도 정답률 100%였으나 정의 ~45k 토큰 비용이 최대; 카테고리 이상조건은 비용 58.3% 절감·정답 유지; Tool Search는 75.9% 최저가이나 정답 80%·첫 호출 65.2% 지연(미검색 2건). 병목은 선택보다 라우터 쪽이라고 정리.

  • 왜 중요한가: 도구 정의 라우팅(전량/캐시/카테고리/Tool Search)의 비용·정답·지연 트레이드오프를 숫자로 고정.
  • 추천: 작게 실험 — Money Forward가 Claude Sonnet 5에 도구 100개를 전량(캐시 유/무)·Tool Search·카테고리 오라클 4방식으로 10쿼리 실측. 전량도 정답 100%이나 정의 ~45k 토큰이 최대 비용; 카테고리 이상 −58.3%·정답 유지; Tool Search −75.9%·정답 80%·Tool Ready +65.2%(검색 미호출 2건). 병목은 선택보다 라우터. 자사 MCP 도구 노출에 같은 분할을 적용할 실측이라 EXPERIMENT.
  • 주의할 점:
    • 10쿼리×1회 소표본이라 일반화 한계.
    • 카테고리 수치는 정답 카테고리를 준 이상 조건(분류기 오차 없음).
    • Tool Search 상주 도구 수/구성에 비용·미검색 실패가 좌우됨.
    • 공식 Tool Search 정답 개선 보고와 반대 방향은 규모·난이도 차이.
  • 다음 단계: 자사 MCP 도구 정의 입력 토큰 수를 재고, 동일 쿼리 3건을 전량 vs 프롬프트캐시 vs Tool Search로 1회씩 비교. 프로덕션 라우터 변경 없음.
