# `drive-export/v1`

This local package is prepared for an approved Drive share workflow. It is not a Drive integration and performs no upload, sharing, or API call.

For every export, fill the [packet template](pathname:///templates/company/drive-export-v1-packet)
from an approved `canonical-content/v1` packet. Preserve the canonical commit,
path, hash, freshness, evidence, action, title, reference, and source links.
The human owner decides whether and where to upload after review.
