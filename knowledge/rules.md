# Knowledge Vault

This is an Obsidian-compatible vault made only of portable Markdown and links.
Open `index.md` in Obsidian or any Markdown editor. Do not commit `.obsidian/`,
workspace layout, plugin state, or machine-specific configuration.

Canonical research remains approved Git SoT. Notes here must link to their
canonical source and commit rather than copying unverified conversation memory.
