# Company Delivery Template Boundary

This template is portable methodology only. It is not a company deployment.

- Use a company-controlled SoT, company account, and company-controlled
  destination.
- Set `repositoryScope: company` in that company-controlled repository; never add company channels to this personal repository.
- Never place company internal data, recipient lists, channel IDs, Drive IDs,
  credentials, or account identifiers in this personal repository.
- Never use this personal GitHub repository as a company canonical source or
  delivery registry.
- Require explicit human approval before an external send or share.
